# Special Education Data Model Domain - Model Diagrams

:::important

EARLY ACCESS DOMAIN (Released in version 6.1) - This domain is being released in
order to allow early adopters a chance to preview and test the proposed update
and provide feedback on its viability for possible future enhancements. This
domain should not be considered fully stable at this time, and it may change
outside of the standard Ed-Fi breaking change release cycle if deemed necessary
by the community. See
[Early Access Material](/reference/data-exchange/versioning-and-releases#early-access-material)
for more information.
