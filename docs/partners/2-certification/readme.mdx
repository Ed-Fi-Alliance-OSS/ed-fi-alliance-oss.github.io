# Ed-Fi Certification

Certifications allow product developers to demonstrate a product's fidelity to
the Ed-Fi Data Standard, and for purchasers or users to be confident that a
product conforms to the same standard and guidelines.

The Ed-Fi Certification program was developed from the experience of many
education agencies in certifying Ed-Fi-compliant data exchanges for their
enterprise systems. The Ed-Fi Alliance has built on that foundation to provide a
certification that can be used across different agencies and organizations,
alleviating the need for vendors to undergo multiple, overlapping local
certifications.

## What Ed-Fi Certification Means

Ed-Fi certification is a technical verification that a product conforms to an
Ed-Fi API specification for a specific Ed-Fi Data Standard version. A certified
product has shown that it:

- Implements the API specification, or can communicate with an implementation of
  it as a client, across all resources and fields marked "required"
- Meets all of the "must" requirements in the API specification
- Meets all of the "must" requirements of the certification itself

Certification does **not** establish:

- Plug-and-play interoperability in every deployment. Local configuration,
  customizations, and business logic (for example, how a school counts
  attendance) still vary.
- That the certified functionality is included in every edition, region, or
  price of a product. The
  [Registry of Ed-Fi Certified Products](./registry-of-ed-fi-certified-products.mdx)
  records the edition and version that was tested.
- Perfect semantic consistency in how a vendor maps its data to Ed-Fi
  definitions, since mapping always involves some interpretation.

**Versions.** Certifications are offered per Data Standard version. The Student
Information Systems, Assessment Outcomes, and Domain API certifications are
currently available for Data Standard v4 and v5; see
[Available Certifications](./available-certifications/readme.md). To see which
Ed-Fi ODS/API and Ed-Fi API versions implement each Data Standard version, see
[Supported Versions](/reference/roadmap/supported-versions).

**Validity.** Certifications are valid for one year and are renewed through
[re-certification](./certification-for-data-providers/recertification.md).

**Certification and badges.** [Ed-Fi badges](../1-badging/readme.md) recognize
support for the Ed-Fi Data Standard and Technology Suite in areas that are not
yet covered by a certification. They are not a lightweight certification. Badges
are generally valid for two years; the Ed-Fi Managed ODS/API Platform badge is
valid for one year.

Agencies should read
[How Agencies Should Use Certification](./how-agencies-should-use-certification.md)
for what is and isn't covered, procurement language, and how to raise gaps with
a certified vendor.
