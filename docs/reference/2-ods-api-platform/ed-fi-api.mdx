---
title: Ed-Fi API (v8+)
---

**Ed-Fi API** (versions 8+) is the new implementation of an HTTP-based API for
the Ed-Fi Data Standard, replacing the Ed-Fi ODS/API. See the [Ed-Fi ODS/API and
Ed-Fi API v8 FAQ](../0-roadmap/api-faq.md) for more information about the
transition from the legacy Ed-Fi ODS/API to the new Ed-Fi API application.
Formal support / maintenance of the ODS/API source code will end June 30, 2029.
