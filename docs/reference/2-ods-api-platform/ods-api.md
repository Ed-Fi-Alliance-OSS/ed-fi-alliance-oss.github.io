---
title: Ed-Fi ODS/API (legacy)
---

**Ed-Fi ODS/API** (versions through 7.x) is the legacy implementation of an
HTTP-based API for the Ed-Fi Data Standard. See the [Ed-Fi ODS/API and Ed-Fi API
v8 FAQ](../0-roadmap/api-faq.md) for more information about the transition from
the legacy Ed-Fi ODS/API to the new Ed-Fi API application. Formal support /
maintenance of the ODS/API source code will end June 30, 2029.

Documentation by version:

- [ODS/API 7.3](/reference/ed-fi-api)
- [ODS/API 7.2](/reference/ed-fi-api/7.2/) (unsupported)
- [ODS/API 7.1](/reference/ed-fi-api/7.1/)
- [ODS/API 6.2](/reference/ed-fi-api/6.2/) (unsupported)
- [ODS/API 5.4](/reference/ed-fi-api/5.4/) (unsupported)
