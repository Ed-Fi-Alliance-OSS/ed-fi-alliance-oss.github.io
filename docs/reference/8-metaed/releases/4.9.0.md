# 4.9.0

Release date: 3 November 2026

:::tip

By default, the Visual Studio Code based editor will automatically update the
MetaEd extension for you. If you are still using the deprecated Atom based
editor, then please see [MetaEd IDE - Upgrading to MetaEd
4.x](../ide-user-guide/upgrading-to-metaed-4x.md).

:::

## Overview

This release adds Ed-Fi API 8.1 as a target, requiring Data Standard 5.2 or later.
It also improves model validation, build and deployment error handling, and
the Visual Studio Code editing experience.

## Changes

### Enhancements

- Added Ed-Fi API 8.1 as a target.
- Added warnings for unresolved Domain Entity members in domains.
- Added validation to reject property names that conflict with reserved query
  parameters when targeting Ed-Fi API 8.1 or later.
- Added snapshot headers and responses to generated Ed-Fi API 8 OpenAPI
  documents.
- Build and Deploy toolbar buttons now appear only for MetaEd files.
- Improved bundled Data Standard model lookup, compatibility messages, and
  read-only protection.
- Updated dependencies, including security fixes.

## Bug Fixes

- Invalid models now produce validation errors without cascading
  artifact-generation failures.
- Deployment is prevented when the preceding build fails. Deployment exceptions
  now produce a failure notification.
- Corrected Ed-Fi API 8 ApiSchema namespace authorization metadata to exclude
  Namespace values inside collections.
