# Agent 2f2: Retrieval Simulation Judgment (questions 127-251)

## Scope

The second half of `drafts/data-standard-audit/questions.yaml`: 125 questions (list positions 127-251, `q-cal-07` through `q-ver-11`). Per-question rows are in `drafts/data-standard-audit/working/findings/2f2.csv`.

## Method

For each question I read the top-3 pages from `working/retrieval-results.csv` against `working/corpus.jsonl`, and checked whether the expected pages contain the answer terms (entity names, learner vocabulary). A question is `yes` if a top-3 page answers it for a newcomer, `partial` if it only half answers it (often an older-version or table-row answer), and `no` otherwise. Miss causes follow the brief. BM25 is directional only; verdicts are human-style judgment from page text, not a rerun of retrieval. AI-assisted analysis: review before use.

## Top Recurring Fix Patterns

1. **Wrong-version and unversioned copies (16).** Teacher, contact, survey and staff questions return v3-v5 copies of the same page because the title, H1 and first sentence do not name the Data Standard version. Fix: name "Ed-Fi Data Standard v6" in the H1 and opening sentence of every domain overview (for example `staff-domain/overview`, `student-identification-and-demographics-domain/overview`).
2. **Non-DS pages outrank domain pages (16).** Analytics Middle Tier, ODS/API, MetaEd, certification and blog pages win on generic terms (attendance, descriptor, "what is the Data Standard", "what's new in 6.1"). Fix: add a plain-language lead sentence with the learner's own words and the entity name on the DS page.
3. **Learner vocabulary absent (12).** Pages say `StaffDirectory`, `StudentDemographic`, `Location`, "target a person type"; learners say email, race and ethnicity, room number, who the survey is about. Fix: add the plain words next to each entity name in the overview prose.
4. **Answers that exist nowhere (11).** Missing: multiple teacher assignments, cohort vs section vs program, why programs attach to sections, domain count, "extended reference", how to read an entities table, Usage Classification, Data Standard vs ODS/API. Fix: write the content, mostly as new sections in the UDM core-concepts page and domain overviews.
5. **Answer in a table row or a very long page (11).** `AcademicHonor`, `CohortScope`, `ImmunizationType` and attendance-event comparisons appear only as entity rows or deep in a 27k-character best-practices page. Fix: one prose sentence in the overview.
6. **Change-history questions ("when added", "what replaced")** work well when the what's-new page matches (`q-staff-06`, `q-ver-04`, `q-ver-07`) but fail when the learner uses version numbers like "5 to 6" rather than "5.0 to 6.0" (`q-concept-23`).

No miss was caused by diagram-only content in this half; model-diagrams pages appear in top-3 only as noise (`q-concept-26`, `q-concept-31`).
