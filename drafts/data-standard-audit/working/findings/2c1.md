# 2c1 - v5 delta audit (first 30 pages)

## Scope

The 30 pages on lines 1-30 of `working/v5-delta-pages.txt`, under
`dataStandard_versioned_docs/version-5/`. They cover the model-reference
sub-pages for 11 domains (Alternative and Supplemental Services, Assessment,
Assessment Registration, Bell Schedule, Discipline, Education Organization,
Educator Preparation Data Model, Enrollment, Finance, Graduation,
Intervention) plus `model-reference/readme.md`.

## Method

- Diffed each v5 page against its v6 counterpart. `educator-preparation-data-model-domain` maps to `educator-preparation-program-domain`, and `student-path.md` maps to `path-domain`. v5 `model-diagrams.md` maps to v6 `model-diagrams.mdx`.
- Parsed the v5 entities tables for row counts, empty-cell ratio and column-count mismatches.
- Inspected built HTML under `build/reference/data-exchange/data-standard/5/` for the visible text, meta description and version badge.
- Checked `docusaurus.config.js` (banner and badge settings) and `docs/reference/0-roadmap/supported-versions.md`.
- Terminology came from `terminology-hits.csv`, filtered to these pages.

## Summary

- Copy/paste error confirmed: the v5 `educator-preparation-data-model-domain/readme.md` opens with the Education Organization paragraph ("The Education Organization domain defines the organizational structure...") under an Educator Preparation H1. The built page's meta description and the page's leading text are therefore wrong. v6 rewrote it correctly.
- Version signal on v5 entity and diagram pages is only the Docusaurus "Version: 5" badge (`banner: 'none'` for v5 in `docusaurus.config.js`). No page body says "Data Standard v5", that v6 exists, or that v5 is supported through 2027-2028. Only `model-reference/readme.md` carries "v5" (in its H1).
- v5 diagram pages are PNG/JPEG images, not Mermaid. The built page for graduation has 17 visible words. Alt texts are generic ("Graduation Domain"), contain a typo ("Education Organizaiion Diagram") or describe the wrong model ("Teacher Prep Data Model Diagram"). The link text "Large Version" and "Click here for a larger view" is weak.
- v5 entities pages are _better_ than v6 on duplication. For example, Graduation has 16 rows in v5 versus 65 in v6, and Bell Schedule has 7 versus 47. v5 lists only domain-owned descriptors, grouped by owning entity, with Usage Classification populated. v6 inherited-descriptor bloat is a v6 regression, not a v5 gap.
- v5 data errors: the Graduation descriptor table has an 8-cell row in a 7-column table. The Finance descriptor table has the typo `ObejctDimension` and the entity name `ChartOfAccount` where the entity is `ChartOfAccounts`. The Educator Preparation entities page still uses the retired name "TPDM" in headings ("## TPDM Domain Entities").
- v5 Alternative and Supplemental Services readme does not link to its own `best-practices.md`, and the v6 readme does. It is the only v5 domain readme with a best-practices page that omits the link.
- v5 `model-reference/readme.md` labels 5.2 "(Latest version)" with no mention of 6.x, so a newcomer could take v5.2 as the current release.
- v5-only text errors on Educator Preparation pages: "an extension to do Ed-Fi core model" (should read "to the"), "or example school year,student", "appled", "decription", "a educator". Several entity-page descriptions are copied from v6-era text.
- Many v6-only improvements are absent from v5, but most are legitimate model changes (DS 6.1 SEORA `ResponsibleEducationOrganization`, `ResidencyStatus` deprecation, new Enrollment overview entities).
