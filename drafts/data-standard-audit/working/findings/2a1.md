# Findings 2a1: Mechanical quality scan, Ed-Fi Data Standard v6

AI-assisted analysis. Review every finding against the source before acting on it.

## Scope

- All 129 v6 rows in `working/inventory-html.csv` (`set` = `v6`): 27 domain-readme, 26 domain-entities, 26 domain-diagrams, 26 domain-overview, 15 domain-other, 6 whats-new, 3 ds-landing.
- Source Markdown and MDX under `dataStandard_versioned_docs/version-6/`. Built HTML under `build/` was used only to confirm absolute links.
- Out of scope for this agent: rendered Mermaid content (R1), per-page rubric scores, terminology classification (2a-T), and v5 pages.

## Method

- A Python scan (`/tmp/claude-0/2a1/scan.py`) parsed every v6 source file. It tracked fenced code blocks and front matter, then ran these checks:
  - Heading outline (H1 count, skipped levels, empty headings, repeated H2 and H3 text across pages).
  - Repeated words and misspelling candidates. No spell-check dictionary is installed, so misspelling detection used a rare-token review: 1,071 lowercase tokens that occur in only one file, reviewed by eye.
  - Placeholder terms, "Go back" boilerplate, and dangling line endings.
  - Relative link resolution, with `.md`, `.mdx`, and `index`/`readme` fallbacks. Absolute links were checked against `build/`.
  - Bullet and emphasis marker counts.
  - Per-column empty-cell ratios for all descriptor tables (the "Name | Entity | Description | Usage Classification" tables on the 26 domain-entities pages).
- Each claim was confirmed with `grep -n` or a targeted `sed`. Line numbers below are file lines from `grep -n`.

## Summary

- 25 findings: 2 H, 8 M, 15 L. Every finding cites a quote or metric.
- Most important: the recruiting-and-staffing overview still contains two `_Coming Soon_` placeholders (2a1-001), and `whats-new-v60.md` links to a repository path that does not resolve on the built site, with the link text "here" (2a1-002).
- Descriptor tables: the "Commonly State-Defined" column is empty in 91.5% of rows across the 26 entities pages. It is entirely empty on 3 pages, and no v6 page defines it (2a1-008).
- Domain landing pages (`domain-readme`) are link hubs. All 91 bullets across the 26 domain-level pages are links to sibling pages, and 24 pages end with "← Go back" boilerplate (2a1-006, 2a1-007).
- Typos and repeated words: 7 confirmed in v6 source (2a1-012 to 2a1-018), plus one brand misspelling ("EdFi", 2a1-019). The rare-token review found no others.
- Naming drift: the domain is called "Recruitment And Staffing" on its pages and "RecruitingAndStaffing" in `api-changes-61.md` (2a1-020).
- Headings: every v6 page has exactly one H1. Three headings skip levels (H2 to H4), and two H3 headings sit back to back with no body text. Generic headings repeat across domains: "Key Concepts" on 27 pages, "Key Entities" on 26, "Extended References" on 25 (2a1-009).
- Links: all relative Markdown targets resolve, apart from a path inside an HTML comment (not rendered). Of 8 absolute links, 7 resolve in `build/`, and the one repository-path link does not (2a1-002). No relative anchor links exist to check.
- Style: bullets use `*` on 2,127 lines across 76 files, and `-` on 7 lines in one file (`whats-new/readme.md`). Emphasis follows the underscore convention (487 lines), with one exception (2a1-025).

## Limitations

- Typos and grammar were checked against the source Markdown, not the built HTML.
- The `that that` finding (2a1-015) may be intentional. Confirm before editing.
- The rubric's Q1 severity scale maps closely to this count, but whether a given typo changes meaning is a judgment call.
