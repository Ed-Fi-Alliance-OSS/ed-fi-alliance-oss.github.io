# Ed-Fi Terminology Guidelines

Source: Ed-Fi Alliance terminology guidance, provided 2026-10-10. Audit-specific
rulings are recorded at the end.

"Ed-Fi" should never be used on its own. Always pair it with a specific
clarifying phrase — such as "Data Standard" or "Alliance" — to make it clear
what you're referring to. This helps avoid confusion, especially for new
audiences, and supports broader adoption.

In most cases, you can use the lowercase version of the clarifying phrase
(e.g., the data standard, the technology suite, the community) after the first
full reference. "Alliance" and the acronyms (e.g. ODS/API) are exceptions to
this rule and should remain capitalized. Just be sure that these references
remain clear. If you aren't sure, use Ed-Fi in front of the clarifying phrase.

## Accepted Uses

### Ed-Fi Alliance

The organization that develops, governs, and drives adoption of the Ed-Fi Data
Standard and the Ed-Fi Technology Suite.

### Ed-Fi Data Standard

The common framework that ensures education data from multiple systems is
consistent, compatible, and secure.

### Ed-Fi Technology Suite

The set of interoperable tools and applications developed by the Ed-Fi Alliance
to implement the Ed-Fi Data Standard effectively.

### Ed-Fi ODS/API

The combined platform offering both a centralized database (ODS) and an API for
seamless data integration and retrieval. General use to describe the platform
in most circumstances.

### Ed-Fi API

The interface that enables secure data exchange among education systems using
the Ed-Fi Data Standard. Acceptable only in API specific documentation.

### Ed-Fi ODS

The centralized database designed to store and organize education data
according to the Ed-Fi Data Standard. Acceptable only in ODS specific
documentation.

### Ed-Fi API Specification

Defines how education data is structured and shared via APIs under the Ed-Fi
Data Standard.

### Ed-Fi Community

The collaborative network of education agencies, vendors, technologists, and
partners working together to improve student outcomes through data
interoperability. "Our community" is an acceptable replacement.

### Ed-Fi Certification(s)

The credential that a product accurately generates education data aligned to
the Ed-Fi Data Standard.

### Ed-Fi Certified Partner

The organization whose products have been verified to accurately generate data
according to the Ed-Fi Data Standard.

### Ed-Fi Badge(s)

The credential for products verified to correctly consume and use education
data aligned to the Ed-Fi Data Standard.

### Ed-Fi Badged Partner

The organization whose products have been verified to accurately consume and
use data according to the Ed-Fi Data Standard.

### Ed-Fi Certifications and Badges

The credentials awarded to products that accurately generate (Certifications)
or effectively consume and use (Badges) education data aligned to the Ed-Fi
Data Standard.

### Ed-Fi Technology Partners

Combined reference to all badged and certified partners. Plural only. Use
approved badge or certified reference in singular use for specificity.

### Ed-Fi Premier Partner(s)

The organizations recognized for exceptional contributions to the Ed-Fi
Community, as well as providing products that accurately generate and
effectively use education data aligned to the Ed-Fi Data Standard.

### Ed-Fi Alliance Summit

An Alliance-hosted national gathering to share practical ways educators use
data to improve student outcomes. Summit (capitalized) is acceptable in
subsequent uses, or when contextualized with the logo containing "Ed-Fi
Alliance".

### Ed-Fi Alliance Tech Congress

An Alliance-hosted hands-on forum for developers and data teams advancing Ed-Fi
Data Standard and its supporting technology in the field. Tech Congress
(capitalized) is acceptable in subsequent uses, or when contextualized with the
logo containing "Ed-Fi Alliance".

## Avoid

- Ed-Fi technology (as a general reference, use "Ed-Fi Technology Suite" or
  "Ed-Fi ODS/API" or "Ed-Fi API" etc.)
- Ed-Fi credentials (be specific, use "Ed-Fi Certification" or "Ed-Fi Badges",
  only use credentials generally without Ed-Fi in front of it.)
- Ed-Fi Badges and Certifications (always Ed-Fi Certifications and Badges)
- Ed-Fi Partner (be specific, "Ed-Fi Certified Partner" or "Ed-Fi Badged
  Partner" or "Ed-Fi Technology Partners")
- Ed-Fi standards (be specific, Ed-Fi Data Standard and/or Ed-Fi API
  Specification)
- Ed-Fi Summit, Ed-Fi Tech Congress

## Additional Guidance: Implement vs. Adopt vs. Deploy

- The Ed-Fi Data Standard is _implemented_.
- The Ed-Fi Technology Suite/API/ODS, etc. is _deployed_.
- The Ed-Fi Alliance _drives adoption_.

## Audit Rulings (2026-10-10)

- **Ed-Fi Unifying Data Model (UDM)** is an accepted term for this audit.
  "Ed-Fi UDM" is acceptable after the first full reference.
- **Ed-Fi API Specification** is the enforced term. The source guidance's
  "Avoid" list said "Ed-Fi API Standard"; that inconsistency is corrected above
  and will be noted in the report.
- There is **no official glossary**. Brand terms are covered here; the report
  may propose a separate glossary of _data model concepts_ (domain, entity,
  association, descriptor, extended reference, etc.) for new learners.
