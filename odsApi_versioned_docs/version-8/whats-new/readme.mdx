# What's New

This documentation introduces the features and significant changes in Ed-Fi API
v8, the platform that replaces the Ed-Fi ODS/API and the Ed-Fi ODS Admin API.

- [What's New In This Release](./whats-new-in-this-release.md) describes Ed-Fi
  API v8.1.
- [What's New in Previous v8.x Releases](./whats-new-in-prev-v8x-releases.md)
  describes Ed-Fi API v8.0.

## Audience

This documentation is for technical professionals who work with educational
data, including business analysts, database administrators, and software
developers.
